# Pixelz — استوديو الرسم والبكسل آرت والأنيميشن

تطبيق Android أصلي (Java، بدون أي مكتبة خارجية سوى `androidx.core`)، يعمل Offline بالكامل، ويستهدف Android 9+ (API 28).

## حالة الاختبار (بصدق)

| ما تم | النتيجة |
|---|---|
| اختبار المحرك (الرسم، التعبئة، الطبقات، التراجع، GIF، حفظ المشروع، القوالب، مسار التصدير) — `tools/run-core-tests.sh` | **143 فحصاً، 0 أخطاء** |
| ملف GIF الناتج فُتح بمكتبة Pillow المستقلة: 8 إطارات، حلقة لانهائية، مدة الإطار صحيحة | ناجح |
| فحص أنواع كل كود Android مقابل واجهات وهمية (`tools/typecheck.sh`) | ناجح |
| **بناء APK فعلي وتشغيله على هاتف/محاكي** | **لم يتم** — بيئتي لا تملك Android SDK ولا اتصالاً بمستودعاته |

لذلك الشاشات والأزرار (طبقة الواجهة) لم تُجرَّب على جهاز حقيقي. أول بناء قد يُظهر خطأ ترجمة صغيراً أو مشكلة تخطيط؛ إن حدث أرسل لي نص الخطأ وأصلحه فوراً.

## بناء الـ APK

### الطريقة 1 — مجاناً من الهاتف بدون كمبيوتر (GitHub Actions)
1. أنشئ حساباً مجانياً في github.com (من متصفح الهاتف، فعّل «سطح المكتب» إن لزم).
2. أنشئ مستودعاً جديداً (New repository) باسم `pixelz`.
3. ارفع محتويات مجلد `kkk` كلها إليه (Add file ← Upload files). تأكد أن المجلد المخفي `.github` وملف `gradlew` ومجلد `gradle` مرفوعة. الأسهل ضغط المجلد ورفعه من الكمبيوتر، أو استخدام تطبيق Termux: `git init && git add . && git commit -m init && git remote add origin <رابط> && git push -u origin main`.
4. افتح تبويب **Actions**؛ سيبدأ البناء تلقائياً (أو اضغط *Build APK ← Run workflow*). يستغرق 5–10 دقائق.
5. بعد النجاح افتح التشغيل ← قسم **Artifacts** ← نزّل `Pixelz-debug-apk` (ملف zip فيه `app-debug.apk`).
6. فك الضغط، ثم ثبّت الـ APK (اسمح بـ «التثبيت من مصادر غير معروفة» لمتصفحك/مدير الملفات).

### الطريقة 2 — Codemagic (مجاني)
سجّل في codemagic.io، اربط المستودع، اختر ملف `codemagic.yaml` وشغّل `pixelz-apk`، ثم نزّل الـ APK.

### الطريقة 3 — Android Studio
افتح المجلد في Android Studio (Hedgehog أو أحدث) ← انتظر مزامنة Gradle ← Build ← Build APK(s).
الملف في `app/build/outputs/apk/debug/app-debug.apk`.

### الطريقة 4 — سطر الأوامر (JDK 17 + Android SDK)
```
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleDebug
```
(`./gradlew assembleRelease` يعطي APK موقّعاً بمفتاح debug ليُثبَّت مباشرة؛ استبدل المفتاح بمفتاحك قبل النشر في المتاجر.)

## الميزات

- **الرئيسية**: المشاريع الأخيرة بصور مصغرة، مشروع جديد (بكسل آرت/رسم، مقاسات جاهزة أو مخصصة، خلفية شفافة/بيضاء)، فتح صورة / GIF / فيديو / ملف مشروع، 6 قوالب، تبديل العربية/English (RTL كامل)، إعادة تسمية/تكرار/حذف بالضغط المطول.
- **الأدوات**: قلم (بكسل حاد)، فرشاة (مُنعّمة)، ممحاة، تعبئة مع تسامح، خط، مربع، دائرة (ممتلئ/حدود)، تحديد، نقل، يد، قطارة ألوان، قص/نسخ/لصق/حذف، استيراد صورة داخل الطبقة، قلب الطبقة أفقياً/عمودياً، مسح الطبقة.
- **أقلام احترافية** (أداة الفرشاة ← زر «نوع القلم» ويعرض معاينة لكل قلم): فرشاة ناعمة، ماركر برأس مسطح، قلم خط بريشة عريضة (45°)، رذاذ ناعم (إيربراش)، ألوان مائية، بخاخ، قلم رصاص، فحم. لكل قلم شفافية قابلة للضبط، وتبقى الشفافية ثابتة حتى لو تقاطعت الضربات. مشاريع الرسم تفتح مباشرة بالفرشاة.
- **التظليل** (أداة جديدة بأيقونة المربع المهشّر): تغميق أو تفتيح أو تهشير فوق ما رُسم، بشدة قابلة للضبط.
- **حجم القلم بسلاسة**: شريط أعرض بحساسية أعلى للأحجام الصغيرة، أزرار − و+ (الضغط المطوّل يكرّر)، معاينة دائرية، والضغط على الرقم يتيح كتابة الحجم بالضبط.
- **التلوين (الدلو)**: «شدة اللون» من 1 إلى 100٪، ووضعان: **عادي** (بالتسامح كما كان) و**داخل الحدود** — يلوّن الشكل كله مهما كانت الألوان بداخله ويقف عند خط الحد فقط. لون الحد يُلتقط بالقطارة، و«مدى الحد» يحدد حساسية الالتقاط، و«سدّ الفجوات» يغلق الثغرات الصغيرة في الخط. يقرأ الحدود من كل الطبقات ويلوّن الطبقة النشطة، فيصلح مع طبقة خطوط منفصلة.
- **التحديد الذكي** (أداة العصا السحرية): المس شكلاً فيُحدَّد بدقة (الشكل كاملاً أو نفس اللون)، ثم قص/نسخ/حذف/سحب يطبَّق على الشكل نفسه فقط لا على المستطيل المحيط به.
- **العرض**: تكبير/تصغير بإصبعين، تحريك، ملاءمة، شبكة (1–32) تُشغَّل وتُوقَّف، معاينة بالحجم الطبيعي.
- **التراجع**: حتى 1000 خطوة (أو 96MB)؛ نقرة بإصبعين = تراجع، بثلاثة = إعادة.
- **الطبقات**: إضافة، تكرار، حذف، إخفاء، دمج للأسفل، إعادة ترتيب، تسمية، شفافية لكل طبقة.
- **الألوان**: HSV + شفافية + HEX، 6 لوحات جاهزة (PICO-8، Sweetie 16، Game Boy…)، ألوان حديثة وألوان محفوظة.
- **GIF/أنيميشن**: إطارات (إضافة/تكرار/حذف/تحريك/مسح)، مدة لكل إطار أو للكل، تشغيل/إيقاف، عدد التكرار (0 = للأبد)، Onion Skin (السابق أحمر والتالي أزرق)، Timeline سفلي بصور مصغرة، استيراد GIF كإطارات قابلة للتعديل، تصدير **GIF متحرك حقيقي** (لوحة ألوان دقيقة للبكسل آرت، median-cut للصور، شفافية، حلقة).
- **إضافة الصور والفيديو**: من قائمة ⋮ ← «إضافة صورة / GIF / فيديو» تختار صورة واحدة أو عدة صور معاً. صورة واحدة تظهر عائمة لتحريكها وتعديلها قبل تثبيتها في الطبقة، وعدة صور تُضاف كل واحدة في طبقة جديدة. عند اختيار GIF أو فيديو تظهر معاينة بشريط تمرير لاختيار **فريم واحد** أو **كل الفريمات** (الفيديو يُؤخذ منه حتى 60 فريماً بأطول ضلع 480px مع الحفاظ على مدته).
- **التصدير**: PNG (شفاف أو بخلفية)، JPG (جودة 1–100)، GIF، ملف مشروع `.pxs` قابل للتعديل؛ دقة ×1…×32 (حتى 4096px)؛ مشاركة مباشرة أو حفظ في أي مجلد (Pictures يظهر في المعرض).
- **الحفظ**: تلقائي بعد 1.5 ثانية من آخر تعديل وعند الخروج؛ استعادة العمل بعد إغلاق التطبيق.
- **اختصارات لوحة المفاتيح**: P B D E G L R O W S M H I، Ctrl+Z/Y/C/X/V/A/S، + − 0، [ ]، Space (من قائمة ⋮ ← المساعدة).

## هيكل الكود

```
app/src/main/java/com/pixelstudio/
  core/   محرك خالص بلا Android (يُختبر على JVM): Doc, Stroke, FloodFill, History, GifEncoder/Decoder, ProjectIO, Raster…
  app/    الواجهة: HomeActivity, EditorActivity, CanvasView, TimelineView, ColorDialog, Exporter, ProjectStore…
tools/    run-core-tests.sh (اختبار المحرك)، typecheck.sh (فحص أنواع بدون SDK)
```

## قيود معروفة
- أقصى مقاس لوحة 2048×2048 (بكسل آرت 512×512)؛ الطبقات × الإطارات الكثيرة بمقاسات كبيرة تستهلك ذاكرة (التطبيق يطلب `largeHeap`).
- GIF يدعم شفافية 1-bit فقط (حدود GIF نفسها).
- سجل التراجع يبقى عند تدوير الشاشة، لكنه يُمسح عند تبديل اللغة أو إعادة فتح المشروع.
